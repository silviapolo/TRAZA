
NODO STUDIO - INSTRUCCIONES

1. ARCHIVOS

Guarda estos cuatro archivos en la misma carpeta:

- index.html
- styles.css
- script.js
- README.txt

2. VER LA WEB

Abre index.html con tu navegador.

También puedes abrir la carpeta desde Visual Studio Code
y utilizar la extensión Live Server.

3. CONFIGURAR WHATSAPP

Abre script.js.

Busca:

const WHATSAPP_NUMBER = "34XXXXXXXXX";

Sustituye las X por tu número real.

Ejemplo:
const WHATSAPP_NUMBER = "34600111222";

No pongas el símbolo + ni espacios.

4. CAMBIAR EL NOMBRE

El nombre NODO Studio es provisional.

Puedes buscar "NODO Studio" y sustituirlo por el nombre
definitivo que quieras utilizar.

5. PROYECTOS

Los dos proyectos incluidos son:

https://silviapolo.github.io/web-entrenador/
http://victoryelisabet.es/

Puedes cambiar las direcciones desde index.html.

6. PUBLICAR EN GITHUB PAGES

1. Crea un repositorio en GitHub.
2. Sube los cuatro archivos.
3. Entra en Settings.
4. Busca Pages.
5. Selecciona Deploy from a branch.
6. Selecciona la rama main y la carpeta /root.
7. Guarda los cambios.

GitHub generará una dirección pública para tu web.

7. IMPORTANTE

El formulario no envía correos electrónicos.
Abre WhatsApp con el mensaje preparado para enviarlo.

Las tipografías necesitan conexión a Internet.
